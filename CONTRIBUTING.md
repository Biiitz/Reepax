# Contributing to Reepax

Reepax is an open-source project, and any help is always appreciated. Whether you want to fix a bug, improve performance, add new features, or refine the user interface, your support makes the app better for everyone.

## In-App Recognition

All contributors are recognized directly inside the desktop application. Once your pull request is merged, your GitHub profile will be featured in the Contributors section inside the app.

## Getting Started

1. Fork the repository and create a branch for your changes.
2. Make your changes and make sure tests pass (`dotnet test`).
3. Open a pull request describing what you improved.

If you have any questions or ideas, feel free to open an issue on GitHub.

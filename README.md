## Overview

**Reepax** is an independent download manager Built with **.NET 8** and **WPF**, it delivers multi-connection acceleration, integrated Rust-powered content filtering, automated PAR2 verification, and archive extraction—wrapped in a clean, modern dark UI.

---

## Features

| Feature | Description |
| :--- | :--- |
| **Multi-Stream Acceleration** | Splits files into parallel connections. |
| **Shielded Browser** | Isolated WebView2 sandbox powered by native Rust AdBlock to safely navigate download pages. |
| **PAR2 Repair & Auto-Extract** | Automated Reed-Solomon integrity checks, archive repairs, and multi-volume `.zip` / `.rar` / `.7z` extraction. |
| **Fluent Dark Interface** | Modern WPF UI with dark theme, clipboard link detection, and bilingual support (EN / DE). |
| **Absolute Privacy** | Strict zero-telemetry policy with local DPAPI-encrypted credential and state storage. |
